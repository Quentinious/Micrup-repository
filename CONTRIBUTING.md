# Contributing

## Branch strategy

- Используйте feature-ветки для всех изменений.
- Название ветки должно содержать Jira key (пример: `MIC-123-add-health-endpoint`).

## Pull Requests

- Jira key обязателен в заголовке Pull Request.
- Изменения в `main` допускаются только через Pull Request.
- Перед merge обязателен code review.
