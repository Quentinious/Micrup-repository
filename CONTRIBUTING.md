# Contributing

## Branch strategy

- Используйте feature-ветки для всех изменений.
- Название ветки должно содержать Jira key (пример: `feature/SCRUM-17-android-bootstrap`).

## Pull Requests

- Jira key обязателен в заголовке Pull Request (пример: `[SCRUM-17] Bootstrap Android application`).
- Изменения в `main` допускаются только через Pull Request.
- Перед merge обязателен минимум один code review (минимум одно одобрение).
- Jira-задача переводится в `Done` только после проверки acceptance criteria.
